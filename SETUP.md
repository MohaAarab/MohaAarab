# Digital Ronin setup

1. Create a public repository named `MohaAarab` on GitHub, matching your username exactly.
2. Copy `README.md` and the entire `src/` folder into the root of that repository.
3. Commit and push. Open your GitHub profile to check the result in both light and dark mode.

All SVG files are self-contained. The hero, about, project cards and footer embed cropped JPEG artwork from the approved concept; text, lines, particles and animated accents are SVG elements. No external fonts, scripts or image services are required. Animation uses SVG SMIL; rendering may vary by browser and GitHub image handling. Static artwork remains visible if animation does not run.

The project links for Mon Dex and Projects Collection intentionally point to repository search results until exact repository URLs are confirmed. E.C.E points to the known repository. Add your verified LinkedIn URL. No example contribution numbers from the concept were included. GitHub activity is linked rather than fabricated.

To customize, edit the SVG source in Zed. Each section is independent. The assets use the palette #101010, #eee3d2, #d63032, #b9ada0. Decorative animated elements are hidden when reduced motion is requested.
